# Freeman — GitHub Actions 网络出口实验

本仓库用于验证 GitHub Actions 托管 Runner 的网络出口与运行时长边界。实验分为：

- **E1：出口 IP 探测**：从 Runner 请求多个公开 IP 查询服务，并比较结果。
- **E2：运行时长探测**：手动指定短时间等待，观察 Job 生命周期与超时行为。
- **E3：本地流量转发**：本仓库当前不开放公网代理；E1/E2 成功并不意味着本地流量已经经过 Runner。若继续验证 E3，应采用受认证的私有连接方案，并确认符合 GitHub Actions 使用政策。

## 运行实验

1. 打开 GitHub 仓库的 **Actions** 页面。
2. 选择 **Freeman: Runner egress probe**。
3. 点击 **Run workflow**。
4. `hold_seconds` 可设置为 `0` 到 `600` 秒；建议第一次使用 `0`。
5. 在运行日志中查看各 IP 查询服务的结果和实验时间戳。

该工作流只在手动触发时运行，不需要任何 Secret，不会部署监听公网端口的服务，也不会修改仓库之外的资源。

## 实验限制

- 出口 IP 可能随 Runner、网络路径或时间变化，不保证固定。
- 不同查询服务可能失败或返回不同结果；应以多次运行结果为准。
- `hold_seconds` 仅用于短时观察，不代表 GitHub 对长时间运行或代理用途的承诺。
- 本实验不会自动证明 DNS、浏览器、IPv6 或本机所有流量都经过远端。
